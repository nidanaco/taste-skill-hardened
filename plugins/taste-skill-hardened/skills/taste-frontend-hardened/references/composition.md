# Composition

Start from the subject: a name, place, material, useful output, constraint, or
piece of evidence. Make that material determine a visual decision rather than
using decoration to manufacture identity.

The offline library contains upstream-derived composition, palette, and type
examples. They are suggestions. Existing brand and product requirements win.

Use a clear first-screen title, one primary action, and enough supporting copy to
explain the offer. Keep text readable at small widths. Use a consistent grid and
spacing scale, deliberate type hierarchy, visible focus, and sufficient contrast.
An unusual composition must still accommodate real content and keyboard use.

Preserve truthful imagery and claims. A missing product photograph is not license
to substitute an unrelated image as if it depicts the product. An honest diagram,
local illustration, or type-led composition is often sufficient.

Prefer fonts already bundled with the project. Do not insert Google Fonts,
Fontshare, CDN scripts, trackers, or remote images as a default. Motion is optional;
respect reduced motion and keep content available when scripts fail.
